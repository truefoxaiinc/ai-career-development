# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include credentials, resumes, or other personal data in a report.

Use the repository's **Security** tab to submit a private vulnerability report. Include the affected component, reproduction steps, impact, and any suggested mitigation. If private vulnerability reporting is unavailable, contact the repository owner privately and ask for a secure reporting channel.

Maintainers should acknowledge a report within three business days, provide a status update within seven business days, and coordinate disclosure after a fix is available. These targets may vary with severity and complexity.

Only the latest deployed version is supported with security updates.
